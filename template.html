The raw values FIRMS returns

The same 5-day window and the same region from each sensor, exactly as the API returned it, for every month where both have detections.

How the two differ: MODIS reports brightness (channel 21/22) and bright_t31 in kelvin with a 0–100 confidence; VIIRS reports bright_ti4 and bright_ti5 with confidence as l/n/h (low/nominal/high). scan and track are the pixel size in km — about 1 km and up for MODIS, about 0.4 km for VIIRS. frp is fire radiative power in MW.

Source: NASA FIRMS area API — MODIS Collection 6.1 (standard + near-real-time) and VIIRS S-NPP 375 m (standard + near-real-time). MODIS counts combine two satellites (Terra, and Aqua from mid-2002); VIIRS counts are from Suomi NPP only. All detection types and confidence levels are included. Data built .
