How the data was harmonized

Step 1 · Raw detections

VIIRS pixels are 375 m, MODIS pixels 1 km, so one fire lights up several VIIRS pixels and VIIRS counts far more than MODIS.

Step 2 · Consolidate same-pass VIIRS pixels

VIIRS pixels in the same 1 km cell on the same satellite pass are counted as one fire. This is the true VIIRS record.

Step 3 · Predict VIIRS from MODIS = model prediction

A model trained on 2012 onward learns true VIIRS from MODIS. Run on 2000–2011, it gives the VIIRS that would probably have been seen: the model prediction.
